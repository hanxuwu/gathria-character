# Standard character kit — actual application evidence

This batch combines two registered hairstyles, two tops, one fixed trouser body and two shoes into eight outfits. Every delivery below was assembled through actual Skin Studio wardrobe controls and downloaded from the application. The same skeleton and all four motion clips are exact across the eight combinations.

Open `.rig.zip` in Skin Studio to edit the self-contained kit. Open `.character.zip` in the independent player for baked playback. The ordinary Character Studio configuration is not a substitute for the imported-art project.

## What was executed

- Actual wardrobe controls assembled all eight combinations from one embedded library; downloaded source slots, bindings and motions matched the prepared snapshots.
- 576 editor comparisons: 8 combinations × 36 source poses × 2 directions. All full native frame pixels matched downloaded PNGs.
- Eight fresh-page project reopen checks retained colors, identities, complete libraries, preview settings, motion data, manifest and rendered PNG pixels.
- 48 actual UI expression captures: 8 combinations × 3 expressions × standing/running. Two additional dark-skin/light-hair/joyful exports preserved all alpha and fixed-material pixels according to source ownership.
- 64 independent player cases after closing Studio: 8 combinations × 4 actions × 2 directions. Every source pose, order, timing, loop wrap and jump final hold/replay was checked against exported PNG pixels. Generator modules were blocked in the player.
- 10 semantic CharacterPacks contain 360 decoded source poses. 36 downloaded ZIPs, 262 delivered PNGs and 48 GIFs passed content decoding and integrity checks. GIF verification preserves manifest timing through cumulative centisecond rounding and compares every decoded quantized frame.
- [Contract validation](contract-validation.json) separately covers all 864 expression/pose cases numerically. It is distinct from the browser capture counts above. [Project verification](verification-results.json) records the tests run by their executor in this task.

Exact commands, timestamps, source/input hashes and results: [execution record](final/current-execution-record.json), [browser evidence index](final/evidence-index.json), [artifact validation](final/artifact-validation.json), [all-file integrity](final/file-integrity.json). Closed-editor screenshots are stored under each combination directory, for example [run right](final/short-teal-boots/independent-run-right.png) and [completed jump](final/short-teal-boots/independent-jump-left.png).

## Scope of the result

Both hairstyles reuse the same expression-face artwork and are selected through the existing identity control. This batch does not add a separate runtime front-hair slot or prove arbitrary body, garment or view interchangeability. The prepared kit has one fixed body and validated compatible assets.

Technical passes and these review artifacts do not grant visual acceptance. The neutral/gentle difference remains subtle, and deep bends retain some angular trouser folds/cuff overlap from the baseline artwork. The separate review document records the final visual findings. The previews use a neutral stage; Gathria production integration remains unverified.
