# 男版落地后的第一步：较低的单脚支撑入口

这是在 main 的 V6 上继续做的小幅优化，不是新增完整的落地转跑动画。男版侧视从原生 Run48 开始接跑，随后按原顺序播放49、50……。旧版直接从49开始，第一步已经进入较高的收腿姿态。

|                | main V6              | 男版 V7 候选 |
| -------------- | -------------------- | ------------ |
| 落地恢复       | 85 → 88 → 89         | 相同         |
| 跑步入口       | 49 → 50 → 51         | 48 → 49 → 50 |
| 接跑时刻、帧率 | 恢复图播放完，24 FPS | 相同         |
| 完整导出流程   | 68帧／2830ms         | 相同         |
| 基础单次跳跃   | 63–90，共28帧        | 相同         |

变化只有男版侧视早期落地路线的入口及配置 ID。女版保留 V6，原视角、起跳路线、晚请求的完整恢复路线、渲染器和原图均不变。既有男版 V6 包和保存的过渡状态继续使用其原配置。

## 改善与限制

在512×768原生画布中，原人物和当前日常换装的可见头顶轮廓均减少约5–6px的首次抬升；对应256×384导出约2.5–3px，属于小幅改善。Run48仍较低，再经过49抬升。带发型在中等透明度阈值下的上移由约21px减为15px，数字会随阈值变化；极高阈值会剔掉半透明头发，不能当作发顶测量。[完整轮廓测量](checks/contour-metrics.json)同时记录原人物与换装、多种阈值，不单独以这个指标判断运动自然度。

原素材中的水平位置和鞋底高度仍有差异，双脚落地到单脚承重也仍缺少真正的中间姿态。这次没有消除“站起再跑”的全部观感，更没有改变舞台移动速度来掩盖滑步。

女版也试过插入 Walk25／26：腿部承重更接近，但手臂会突然垂下，再回到屈肘跑姿，袖口轮廓也跳变，因此舍弃。女版 Run40 入口会增加头部先降再升，仍保留 Run41。[被舍弃的走路姿态诊断](review/female-walk-rejected.png)来自已烘焙原图集，明确不是新应用导出。

继续显著改善需要专门制作落地后转移重心、送出第一步的素材，并分别适配服装。这个候选只保留已证明较温和的男版首步调整。

## 使用与验证

工作台选择男版、侧视、单次跳跃模式，先跑步再点“跳一次”。新会话使用男版 V7；保存的 V6 过渡状态和历史独立包仍保留原入口。

[技术验证记录](verification.md)与上述视觉判断分别记录。实际导出的检查凭据保存在 `checks/`，比较图生成方法见 `scripts/build-landing-first-step-review.py`。
