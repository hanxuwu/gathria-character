# 男版 V7：实际应用导出视觉评估

已从 `/tmp/landing-v7/exports/male/` 的实际 `side-run-jump-run-right.gif` 和 `side-run-jump-run-left.gif` 运行审阅脚本，与 main 已提交的 V6 实际下载对比。没有用诊断序列代替缺失下载。

## 判断

这是可保留的小幅改善，不是完整的自然落地接跑解决方案。

实际同时间全身图里，最后恢复图89之后，V7先出现Run48：身体比V6直接进入Run49略低，第一张跑姿保留更清楚的单脚支撑，再进入49收腿、50前迈。头部上升的第一跳更小，手臂仍保持屈肘跑动，未引入此前逆向借图或Walk桥的反向摆臂、垂臂再抬臂。

当前落地窗口没有看到因这次入口改变新增断肢、鞋腿分离或脸型变形。所有使用的图都来自同一批既有图集；衣服原有的褶皱变化仍存在。这轮未补绘衣服。

## 仍然可见的限制

89→48还是跨源片段的切换，躯干从双脚下蹲恢复转为单脚跑姿时，身体横向位置和脚底高度差仍可见。不能称为真正连续的“压地、重心前移、第一步推蹬”，也不能因为头顶跳变变小就声称没有卡顿。前面的双脚恢复段仍有短暂站起再跑的观感。

原生裸头轮廓的头顶抬升由约19–20px减为14px，即约5–6px；这只是轮廓顶点指标，不是头部质心或骨骼运动测量。有发型图的alpha阈值会改变绝对数值：中间阈值约21→15，alpha非零为12→6，极高阈值会排除Run48几乎不透明的头发。不能选择单个有利阈值证明自然程度。
