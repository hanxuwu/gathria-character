# 落地后先迈步，再恢复跑步

侧视男女角色现在保留落地、下蹲缓冲和前三张恢复画面，随后用两张已有的前倾迈步画面接入跑步。相比 V4 等到双脚站直才切换，第一步更早展开，正式 Run 提前两帧，约 83ms。

| 人物 | V4 落地末段                    | V5 落地末段          |
| ---- | ------------------------------ | -------------------- |
| 男版 | 85 → 86 → 87 → 88 → 89 → Run55 | 85 → 63 → 62 → Run53 |
| 女版 | 80 → 81 → 82 → 83 → 84 → Run47 | 80 → 58 → 57 → Run45 |

表中均为原图集 frame ID。两张衔接画面来自原视频的起跳前迈步，以相反顺序重排使用；**原视频没有这段连续的落地接跑动作**。本轮没有重新生成、变形、移动或插值人物画面，脸型、比例、服装与原图集保持原样。

## 页面中试用

1. 打开 `/workbench.html?mode=paired&character=male`，女版将参数改为 `female`。
2. 选择侧视、单次跳跃，开始跑步，再点击“跳一次”。落地后短暂显示“落地接跑步”，再继续 Run。
3. 在恢复段暂停、保存双视角项目并重开，检查画面及剩余过渡时间；恢复段重复按 Jump 不会追加第二跳。恢复完毕后可主动再次起跳。

原地单跳仍是完整 28 帧；落地回 Idle/Walk、错过早期出口的兜底路线，以及原视角 V2 均保留。侧视新配置为 V5，历史 V1–V4 包保留原路线。双视角项目沿用 `takeoff` 字段保存两种经过验证的过渡状态，旧项目可读；含新过渡状态的项目不保证旧版应用可读。

## 视觉边界

改善的是“缓冲后站一下才跑”的第一步姿态，不能据此称为无缝动画。第一张衔接图的手臂后摆和双足到分腿仍有较快变化；原图的头部俯仰、鞋掌滚动及既有发型、衣料边缘差异仍可见。继续消除这个接缝需要补画专门的重心转移帧，并为可换装图层同步适配。

[选帧理由](selection.md)记录排除的方案；[功能与视觉验收](verification.md)分别报告结果。
