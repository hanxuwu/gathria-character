## 为何先进入 Run53 / Run45

下一帧 Run54 / Run46 的脚掌已经向后收且下降；直接进入会省掉一步展开过程。保留 53 / 45 将前脚收回与下降分成两拍，再以原生 24 FPS 播放 54 / 46。

固定原图坐标下，亮色前鞋区域的质心用于辅助比较，不作为踝关节的真实坐标：男版 62 → 53 位移约 (-49, -2)px，直接进入 54 约 (-68, +16)px；女版 57 → 45 约 (-42, +8)px，直接进入 46 约 (-62, +28)px。男女分别比较后，都支持保留较早一帧。逐项值见 [采样记录](checks/front-shoe-time-samples.json)。

## 排除的方案

- 维持 89 / 84 才接跑：较接近跑步经过位，但仍保留双足站直的停顿观感。
- 再多保留 86 / 81：头部先抬起再转为前倾，面部俯仰的切换更明显。
- 提早到 83 / 78，再插入 64 / 59：出现更深的下蹲和闭眼，像再次蓄力。
- 借用 Walk：先变直立、放下手臂，再接回弯肘跑步，增加一次姿态突变。
- 沿用 90+ / 85+：进入第二次跳跃；更后面的终末恢复仍是双足着地，没有所需的第一步。
- 仅删掉恢复帧：缩短等待，但无法补出腿部的向前展开。

## 仍然存在的限制

85 / 80 → 63 / 58 的近侧手臂从腰旁突然向后摆，双脚支撑也较快变成分腿。倒序使用迈步图还会反转原来的鞋掌滚动。头部位置整体向上恢复，不等于头部俯仰完全连续；不能用整个人物的透明像素边界代替头部测量。

本轮作为已有素材范围内的接跑改进交付。实际同时间近景和 GIF 能看到改善，也保留这些接缝供复审；最终自然程度不由单元测试决定。
