# 落地恢复保持正向，再接低收腿跑姿

V5 没有通过用户对自然程度的验收。它将起跳前的画面倒序插入落地，导致头部俯仰和摆臂方向反复改变。画面更有力度，不等于衔接更自然。本轮撤掉这段逆向借图，改用实际落地恢复画面。

| 人物 | 被拒绝的 V5                         | 当前 V6 候选                      |
| ---- | ----------------------------------- | --------------------------------- |
| 男版 | 落地85 → 起跳前63、62 → 大跨步Run53 | 落地85 → 恢复88、89 → 低收腿Run49 |
| 女版 | 落地80 → 起跳前58、57 → 大跨步Run45 | 落地80 → 恢复83、84 → 低收腿Run41 |

仅省略两张近似恢复姿势：男版86、87，女版81、82。接触、压缩及之后的恢复保持原素材正向顺序；基础 Jump、Run、起跳路线和原视角不变。V5 与 V6 的完整流程均为男版68帧、女版65帧，逐帧时长相同。这次改变姿态接续，没有再次加速，也没有生成、插值或变形人物。

## 实际边界

V6 消除了 V5 借图带来的低头、甩臂再复位，并选用更收拢的腿型进入第一步，但不能承诺完全自然。原片是双脚落地后站起，Run 则已进入稳定单脚节奏，本来就缺少两者之间真实的重心转移画面。

最后恢复图与跑步入口仍有差异：男版头顶上移约20个原生像素、鞋底高度相差约9px；女版约8px、4px。对比图没有逐帧移动或缩放人物去掩盖这些差异。若要求消除这一层接缝，需要专门补画“落地支撑 → 重心前移 → 第一步”的过渡素材及相应服装层，继续换帧无法保证解决。

在工作台刷新后，选择侧视、单次跳跃，播放 Run 再点击“跳一次”即可试用。旧 V5 包和保存的过渡 checkpoint 仍按其原配置读取，不会被静默改写；新会话采用 V6。
