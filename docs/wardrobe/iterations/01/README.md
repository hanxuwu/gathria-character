# Initial wardrobe export: ankle gap

These are frozen actual application exports from implementation recovery point `90fae7f0ed1e9c210c4c5467fad63920e7f240a6`, before the final articulated shoe fit. They are comparison evidence, not the recommended final examples.

The resting ankle fit appeared connected, but full animation exposed a thin gap between trousers and flats. The exported `waves-mixed` atlas contains a detached 359-pixel shoe component in nine poses. `connections-3x.png` shows the run pose 6 gap. The final exports at the top of `docs/wardrobe/` add a small source-owned shin allowance and explicitly retain it behind the shoe.

The two CharacterPack ZIPs remain independently playable exactly as exported. No intermediate editable wardrobe project is provided in this archive. Use the final project ZIPs in the parent review directory to continue editing.
