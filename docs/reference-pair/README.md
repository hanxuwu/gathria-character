## Use

| Character          | Independent playback                           | Editable complete project          | Reusable identity                                                   |
| ------------------ | ---------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------- |
| Theo / navy suit   | [CharacterPack](final/theo-theo.character.zip) | [Project](final/theo-theo.rig.zip) | [Identity](../../artwork/reference-pair/prepared/theo.identity.zip) |
| Rose / coral dress | [CharacterPack](final/rose-rose.character.zip) | [Project](final/rose-rose.rig.zip) | [Identity](../../artwork/reference-pair/prepared/rose.identity.zip) |

Each project embeds both identities and all six garment items. Open it in
`/skin-studio.html` to customize and save. Open a CharacterPack in `/player.html`
to play without the editor or source assets. Keep the project for later edits;
the baked pack contains pixels, not an editable identity library.
