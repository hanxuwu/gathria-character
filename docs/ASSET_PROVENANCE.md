# Original pixel art and reuse

The character artwork in `src/core/generator-v1.ts` and `src/core/generator-v2.ts` was designed and implemented specifically for Gathria Character. Both renderers use original, integer-coordinate pixel shapes and palette rules; `src/core/generator.ts` chooses the renderer from the saved configuration version. No external sprite sheet, character pack, traced artwork, fonts, or third-party image assets are included in the character generator. The Mira, Rowan, and Jun presets use these original shapes.

Retain the MIT copyright and permission notice when redistributing. There is no mandatory visible in-game credit or per-export fee. Generated packs include the license text for convenient redistribution. This statement covers this repository's original artwork; users remain responsible for any assets they independently add.

Both artwork versions draw transparent 48 × 64 frames in a 384 × 128 PNG. Four idle drawings occupy columns 0–3 of row 0, and eight walking drawings occupy row 1. Frames share a ground anchor at `(24, 60)`. Native artwork faces right; consumers can mirror complete frames to face left. Pixel geometry is deterministic and contains no randomness, remote image requests, or model calls.

V1 artwork is preserved in its original renderer, saved configurations, and `public/samples/` packages. Art V2 uses a separate renderer and explicit configuration `artworkVersion: 2`. It provides three face shapes, four hairstyles, five upper garments, and four lower garments, including editable casual and wedding outfit presets. Clothing, face, and hair shapes are independently selected; skin, hair, upper clothing, lower clothing, and shoes each have their own base color and derived shading.

Art V2 samples in `public/samples/v2/` and review images in `docs/art-v2/` come from actual application exports. The review script assembles those pixels at native size or integer zoom. Its labeled neutral scene is a preview backdrop, not a Gathria scene asset or evidence of production integration. AI/photo generation and production Gathria integration remain separate future milestones.
