## 测试中发现并处理的问题

首次女版加载失败是新定位 JSON 的缩进使文件达到 1,069,980 字节，超出已有 1 MiB 限制。修正为紧凑 JSON 后为 442,187 字节，语义和像素没有变化；没有提高运行时上限。生成器及真实发布素材测试新增大小、哈希和绑定检查。女版相关用例随后重跑通过。

另一次独立审计把较宽的“拳头到袖口”审阅区域都当作裸手，错误地要求完整换装图等于裸素材。实际新／旧包在该区完全相同：471 个既有覆盖像素中 470 个来自袖口、1 个来自原有头发边缘。最终检查同时要求：

- 整个 4,108 像素审阅区与旧实际导出精确相同；
- 真正近手保护区中 1,714 个不透明像素与原片精确相同；
- 此区域原先未被覆盖的像素继续与原片相同；
- 新头发改动仅限已审阅的 373 像素释放区，衣料改动仅限记录的差异遮罩。

没有用宽容误差绕过失败。此处修正的是“裸手”和“既有袖口覆盖”的验收语义；素材没有因这次审计而改动。女版最后完整用例再次通过，18 份重导出输入与此前已审阅文件 SHA 相同。具体尝试与文件记录见 [浏览器汇总](review/checks/summary.json)。

## 视觉检查

已审阅实际 UI 导出的左右动作、跳跃全序列、完整原生帧，以及原片／修复前／修复后的整数倍局部图。结果：女侧 95 肤色斜线消失；女侧 97 前臂碎片清除；男 81／82 前肩轮廓更连续；女待机／行走后肩凹口变顺。检查相邻姿势未发现由本轮修改新增的明显局部跳变。原版和未列出的原生衣料／头发区域由严格像素检查约束保持。

视觉验收仍有明确限制：女版部分旧袖口截平与腰线楔片、男版部分后肩细条和较硬的衣料褶皱仍在；男侧 100 的原片耳颈肤色／绿幕边缘没有修复。源视频本身的头形、亮度和姿势变化也保留。**本轮是明确局部改善，不作全帧无穿帮结论。**

作者离线诊断位于 `artwork/paired-polish/`；最终审阅图位于 `docs/paired-polish/review/`。后者来自应用导出，没有用离线合成图冒充编辑器导出。比较 GIF 使用固定展示倍率和各自原生时钟，跳跃不强制循环，显示结果不写回原生包。
