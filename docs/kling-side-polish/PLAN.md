## Parallel work

1. Integration: freeze source contracts, coordinate shared registrations, inspect
   visual changes and publish the reviewable draft without merging it.
2. Male clothing: source-trace walk frame 26's hand/shorts boundary and preserve
   accepted run-contact repairs and unrelated cloth pixels.
3. Female clothing: reduce visible donor switching in the skirt and inspect
   sleeve/cuff and hem continuity without changing source poses or timing.
4. Hair: inspect ear/nape overlap and all action/color combinations; update
   source bindings after reviewed registration changes.
5. Authoring: reusable painting-guide export and actionable package preflight.
6. Workbench: same-frame comparison, slow inspection, magnified details and
   source-scoped problem-frame notes.
7. Performance: measure actual loading before optimizing, preserve cancellation,
   retry, validation and mutable project isolation.
8. Independent QA: inspect final files and actual exports, save/reopen, old
   projects, both directions and a fresh standalone player.

The environment permits seven concurrent agents including the integration lead.
Six implementation agents start together; independent QA joins when a slot is
released. Ownership of shared files is agreed before edits.

## Acceptance

- Source ZIPs, frame IDs, 512 × 768 native dimensions, `(256, 710)` anchor,
  24 fps and existing loop flags remain unchanged.
- Original face/body pixels outside authored ownership remain unchanged.
- Candidate registration changes propagate to matching garment and hair banks;
  old saved projects retain embedded old bindings.
- Every retained visual repair has same-frame before/after evidence; complete
  actual-export clips establish whether it behaves well in motion.
- Preview slow motion, guides and review notes must not change exported artwork
  or source timing.
- Performance claims include observed measurement conditions; technical tests
  and visual conclusions are reported separately.
- The existing jump remains its original two-jump one-shot. No invented frames
  or retiming are added to conceal its crouched endpoint or source blur.

Bulk intermediate work is kept under `/tmp/side-polish/`; only selected final
evidence is retained in the repository because the workspace volume is nearly
full. The previous review and all source artwork remain available.
