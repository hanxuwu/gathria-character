# Running limb ownership and joint connections

This batch repairs moving-arm fragments and bent-leg seams while retaining V6 artwork and the compact run's poses and pace. It branches from the verified PR #2 merge, `ebec736e72966923304281bc0150505ae04f1c99`, on `fix/run-limb-connections`; the new draft PR targets `feat/character-art-v2` and remains unmerged.

## Causes and fixes

| Defect                                                    | Confirmed cause                                                                                                                                                                                               | Scoped repair                                                                                                                                                                                                                                                                                                                                    |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Coral's blue strips beside raised hands                   | The soft-top forearm cuts included neighboring skirt pixels. Most are fixed ink (material 0), so filtering blue or lower-clothing colors would remove legitimate design details and miss the ownership error. | [`running-arm-parts.ts`](../src/core/running-arm-parts.ts) traces the original inner arm and hand contours in source coordinates. Each forearm loses 63 foreign pixels; 14 near-arm and 13 far-arm pixels are recovered from overlapping source cuts. Ten far-arm material labels are corrected for skin recoloring.                             |
| Coral's extra skin and broken waist silhouette            | Original standing-arm pixels were retained on the torso and skirt cuts, then appeared alongside the moving arm.                                                                                               | The same ownership adapter removes 67 torso, 58 skirt-hip and 80 skirt pixels belonging to the original arms. It retains the actual garment pixels, including the blue underskirt. The repaired layers have separate `motion3:` IDs so cached legacy decoding cannot replace the corrected pixels.                                               |
| Denim/Ochre knee spikes and Sage's cut-looking bare knees | Thigh and shin textures were cut horizontally around the knee with only three source pixels of overlap on each side. Independent rotations exposed the rectangular caps during deep flexion.                  | [`running-leg-parts.ts`](../src/core/running-leg-parts.ts) reconstructs one continuous source strip and samples it along the existing hip–knee–ankle path. A bend confined to at most five pixels around the knee joins the segments. Original cloth, skin, cuff and sock pixels provide the texture; there is no generic flat-color knee patch. |
| Cuff/ankle fragments and duplicate shoe edges             | The old shin slice included shoe pixels, while the shoe was also drawn with its own pitch. Generic end trimming could over-narrow the remaining shin.                                                         | The connected strip removes only pixels owned by the matching shoe layer; that shoe is drawn once with its preserved transform. Source-specific leg width and cuff/skin rows replace the generic three-pixel ankle cap.                                                                                                                          |

The jacket and hoodie arm ownership already followed their sleeves and passes through unchanged. Existing near/far limb ordering, shoulder and wrist targets, body lean/bob, foot placement, shoe pitch and hair/cloth timing stay in [`running-rig-v3.ts`](../src/core/running-rig-v3.ts). Head, neck, face, proportions and expression artwork are unchanged. No new illustration or image-generation call was needed. [Source-layer diagnostics](run-connections/diagnostics/coral-layer-ownership-3x.png) and the [coordinate audit](run-connections/diagnostics/arm-ownership-audit.json) explain the extraction; they are labeled diagnostics, not finished-character evidence.

## Compatibility and verification

The repair declares `artworkVersion: 6`, `motionVersion: 3` and generator `gathria-polished-pixels-v6-motion-v3`. [`generator-motion-v3.ts`](../src/core/generator-motion-v3.ts) copies the original V6 idle/walk rows and appends 12 run frames at 18 fps. Frame size 192 × 256, anchor (96, 240), mirrored left playback and CharacterPack manifest v1 stay unchanged. GIF presentation uses 12 frames over 670 ms after centisecond rounding; exported animation timing remains exactly 18 fps.

New V6 configurations use Motion 3. Existing saved V6/Motion 1/Motion 2 files keep their renderer; **Create corrected running copy** explicitly opts into the repair. V1–V7 artwork and earlier motion modules, source banks and packages are preserved. Legacy packs without Run continue to load with that action unavailable. Runtime generation remains deterministic and local.

Independent static review examined all 48 candidate run poses and enlarged connection crops. It found the former hand strips and static waist skin absent, the legitimate blue hem retained, and continuous bent knees/ankles without the previous large cut spikes. Same-phase head pixels through y=110 and the complete idle/walk atlas rows were independently compared byte-for-byte with the frozen before exports. The 11→0 pixel-change count stayed within the ordinary adjacent-frame range for each look. These are static/temporal checks, not a claim that the reviewer visually watched real-time playback; the separate browser recording and pixel checks document actual playback functionality.

**Executed in this batch:** 284 unit tests across 16 files and 26 Chromium E2E tests passed; TypeScript and the production build passed. The retained-artwork editor bundle still produces its existing size warning. File verification decoded 61 PNGs, 48 GIFs with exact source-frame order/timing, 12 before/after/regression ZIPs plus four retained iteration ZIPs, and the full 23.36-second player recording. Four public samples match their reviewed ZIP bytes. Eight closed-Studio run cases (four looks × two directions) observed every declared frame and matched exported PNG pixels; no browser errors, external requests or forbidden generator/editor imports occurred. [Verification record](run-connections/verification-results.json) and [file report](run-connections/file-validation.json) retain the results. These are current executions, separate from previous milestone counts and from aesthetic acceptance.

## Remaining limits

Deeply folded bare knees now form a pronounced rounded U shape. Hands and boots retain their original articulated cutout drawing, and cloth still deforms from existing source pixels rather than bespoke painted run poses. The skirt's retained blue trim and left-side fold are intentional source details. This batch does not change running rhythm, garment designs, expressions or the underlying motion style. It does not establish production Gathria integration, world movement/foot-speed matching or user visual acceptance.
