# 第二版独立视觉检查

结论：**第 108 帧的上身衔接和男版西装的近侧抬臂袖形有明确改善，适合作为独立实验候选继续审阅；不等于落地接跑已经完全自然，也不提升为默认人物。** 检查使用实际工作台导出的左右 GIF、原尺寸 PNG、CharacterPack，以及 16 张困难姿势的同帧前后图。

## 实际改善

- **107 → 108 → Run48**：旧 107、108 的近侧手臂几乎保持同一姿态，变化集中在腿部，随后到 Run48 时手臂突然下摆。新 108 提前移动肘部和拳头，并收窄胸前轮廓，减少了这一次上身跳变。原人物、日常衬衫和西装的实际导出均呈现这项修正。最终版本已清除拼接初稿在胸部与远侧手臂之间出现的重复黑线；近侧手与腰部没有新增露缝。
- **日常装 108**：袖口随新的肘部位置衔接裸露前臂，未见新增断口。**西装 108**：布料和象牙色袖口随拳头下移；弯曲手腕旁可见的三角形白色区域是袖口，不是皮肤漏出。
- **西装 63–66、74–80、97–101**：近侧袖子从方形覆盖块改为沿手臂方向弯曲的布料；63、66、75、76、77、78、80 的改善尤其清楚。78 的小块暖色腋下漏孔已关闭，100 的袖口下方悬垂肤色小角已移除。四张完整对照图中未见新的人脸、手部或腿部形变。

## 尚未解决的视觉问题

- 新 108 降低了摆臂突变，但补绘帧和原片 Run48 的身体阴影、轮廓与姿态仍有差异。不能据此宣称过渡完全无感。
- 本次没有改变腿脚或动作时钟，之前测得的支撑脚相对地面位移仍然存在；原地 GIF 也不能证明锁脚。
- 西装 74、97 的急弯手臂在袖口下方仍有较突兀的肤色转折；100、101 的袖口偏高，略像挽起袖子。77、78 等姿势的远侧袖子仍保留此前的方形边界，本轮修正集中在近侧手臂。
- 完整演示 GIF 的结尾回到开头是 `Run47 → Run39` 的演示重播，并非无缝跑步周期。运行时控制器会继续跑步循环；这里的跳变来自演示文件从末尾重播。不要把这个重播边界与落地过渡混为一谈；每轮演示仍只跳一次。
