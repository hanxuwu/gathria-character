# 双视角衣橱

原版三分之四视角和侧视共用一套服装选择，但分别使用各自绑定原片的衣料素材。
本轮提供男女各一套「棉质背心 + 棉短裤」，每人都可选海盐蓝或暖杏色配色，保留原片白鞋。
这是一种剪裁、两种配色，没有把已有衬衫或裙子冒充侧视的同款。

## 打开与使用

运行 `npm ci`、`npm run dev`，打开 Vite 显示的地址：

1. 首页点击人物卡片中的 **编辑人物**。
2. 选择 **双视角衣橱** 页签，等待两个视角载入完成。
3. 选择人物、配色、上装和下装；上装或下装可以单独恢复原片。
4. 在页面顶部 **人物素材** 中切换原版和侧视，当前服装选择会保留。
5. 选择动作、朝向、帧位，或点击播放。每个视角保存自己的预览状态。

直达地址：

- 男版：`/workbench.html?character=male&mode=paired`
- 女版：`/workbench.html?character=female&mode=paired`
- 侧视初始预览：加上 `&view=side`。

旧衣橱、侧视试装、原片动作、主题和可选骨骼工具继续保留。这里的共用选择目前只适用于已配对的轻便日常款，旧衣橱中的任意服装不会自动获得侧视版本。

## 两个视角如何对应

一个逻辑搭配记录款式、配色、上装和下装 ID。每件衣服都有独立的 `original` 和 `side` 资源，由人物、原片 SHA-256、定位文件 SHA-256 和衣料包 SHA-256 共同约束。

切换搭配前会准备并校验两个视角，均成功后才应用；缺失资源、损坏项目、取消操作不会留下只换好一边的状态。两个视角不共用图片缩放、帧编号或同一组关节坐标。

| 内容           | 原版                         | 侧视                       |
| -------------- | ---------------------------- | -------------------------- |
| 原生单帧尺寸   | 704 × 1056                   | 512 × 768                  |
| 男版独立原画帧 | 88                           | 107                        |
| 女版独立原画帧 | 96                           | 102                        |
| 动作           | 待机、走路、跑步、跳跃、庆祝 | 待机、走路、跑步、连续两跳 |
| 时间           | 保留原动作帧序与帧率         | 保留原动作帧序与帧率       |

侧视庆祝明确显示不可用。侧视跳跃保留原片连续两跳并在末尾停止，不伪造无限循环或借用原版姿势。

## 保存与导出

- **保存双视角项目**：`gathria-dual-view-wardrobe` V1 ZIP，含清单及两份完整原生换装工程。保存服装选择和各自的动作、方向、帧位；重新打开后继续编辑。
- **当前视角换装工程**：原有原生格式，可在对应旧工具打开。
- **当前帧 PNG / 当前动作 GIF**：使用当前视角和朝向的实际合成结果。
- **当前视角 CharacterPack**：使用已有导出格式，包含该视角支持的动作，可由独立播放器加载。

双视角工程是编辑存档，播放器使用其中某个视角导出的 CharacterPack。没有改变旧 CharacterPack 或原生换装工程的格式。

导入时检查两份原生工程的完整性、人物身份、来源绑定、资源版本和逻辑选项对应关系。不会仅凭名称把未知衣服识别成某个已审阅款式。

## 素材与实现

- [素材目录](assets/catalog.json)：16 个衣料包，包含男女、两个视角、两种配色和两个部位。
- [美术来源与处理记录](../../artwork/dual-view-wardrobe/README.md)：12 个局部材质变体、4 个原画不变的资源别名；不是新生成的人物。
- [构建核对数据](../../artwork/dual-view-wardrobe/verification.json)：786 次原生姿势组合检查，衣料之外的像素和整体透明度保持不变。
- `src/wardrobe/dual-view.ts`：双工程存档和严格导入校验。
- `src/wardrobe/dual-view-catalog.ts`：逻辑款式到各视角原生资源的解析。
- `src/wardrobe/DualViewWardrobe.tsx`：原子应用、预览、保存与导出界面。
- `src/workspace/Workbench.tsx`：现有工作台入口与素材切换。

## 验收与限制

当前运行的功能与实际导出检查单独记录在 [verification.md](verification.md)，历史测试数字不计入本轮。审阅材料来自工作台导出的 PNG、GIF 和 CharacterPack。

- 两种视角跑步并排：[男版](review/male-views-run-right.gif) · [女版](review/female-views-run-right.gif)。每边按自己的原始时间播放，三秒审阅图播完停止，不表示两个视频的帧位相同。
- 跑步关键帧：[男版](review/male-run-keyframes.png) · [女版](review/female-run-keyframes.png)。图中分别注明动作内的帧位。
- 完整左右动作 GIF、原生 PNG、工作台与独立播放器截图：[男版](review/male/) · [女版](review/female/)。
- 独立 CharacterPack：[男版原版](review/male/original.character.zip) · [男版侧视](review/male/side.character.zip) · [女版原版](review/female/original.character.zip) · [女版侧视](review/female/side.character.zip)。

GIF 沿用当前应用的半尺寸、不透明底色导出方式；PNG 与 CharacterPack 保留原生分辨率和透明度。并排 GIF 直接排列应用导出的画面，统一审阅调色板；单独动作 GIF 是应用下载的原始文件。

技术检查通过不等于新美术已经完全统一：原版视频运动帧更模糊，两个视角的明暗、细节和身体投影仍有差异。女版原版短裤保留了较明显的侧缝高光。此次没有更改原人物、修补原动作、补出庆祝动作或让任意旧服装自动适配侧视。

以后增加同款衬衫、裙装或发型，需要分别完成两个视角的姿势、遮挡与素材审阅，再登记为同一逻辑款式；不能通过复用原版衣片获得可靠的侧视效果。
