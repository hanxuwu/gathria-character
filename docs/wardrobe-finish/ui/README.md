# 工作台覆盖检查点

使用现有原视角与侧视审阅面板，不新增角色页面，也不修改动画、定位或服装素材。

## 入口

- 原视角：`/workbench.html?character=female&mode=wardrobe`，打开 **Open look review**。
- 侧视：`/workbench.html?character=female&mode=side-view&collection=tailored`，打开 **检查穿帮 · 逐帧审阅**。
- 男版落地候选：`/workbench.html?character=male&mode=side-view&collection=landing-candidate`，打开同一逐帧审阅面板。

面板中的 **已记录的覆盖检查点** 按当前源文件 SHA、实际注册帧和动作帧绑定。
例如女版原视角 62 是跑步交叉手臂位置，90 是下蹲腰线；男版候选 97/100/101 用于抬臂袖口复核。
它们是已知需注意的位置，不是当前搭配一定有问题的告警，更不会自动标记美术验收通过。
未知或不兼容的导入原片不会套用相同数字的检查点。

点击检查点后暂停到对应原生帧，保留当前服装、发型、表情与朝向，并选择相关局部区域。
如果侧视单次跳跃模式没有该原生帧，沿用既有审阅行为切到完整原片动作，并显示状态说明；单次跳跃定义及导出动作策略未被改写。

## 同帧审阅与导出

- 原人物与当前搭配保持同一帧、同一裁切。原视角还可保留原有的固定搭配对比，定位检查点时切回原人物作参考。
- 原视角增加 1×/2×/3× 查看；侧视沿用 2×/3× 局部查看。放大图在窄屏内滚动，不拉伸人物。
- **显示服装覆盖区域**：青色表示当前选中服装的绘制 ownership，粉色表示有意清除旧衣的透明替换区域。按鞋、下装、上衣、连衣装的实际层序叠加；头发 padding 与左向镜像均保留对齐。
- 覆盖图是服装声明范围，不是肤色检测、穿帮得分或最终前景层判定。头发等外观层可能在衣服前方。
- **下载本帧 PNG（无标记）** 导出对应姿势与朝向的完整原尺寸透明人物。缩放、局部裁切和覆盖色都只影响审阅显示，不能写入 PNG、GIF 或角色包。

现有逐帧问题记录、慢放、审阅包与保存重开继续可用。

## 验证

- `src/wardrobe/coverage-review.test.ts`：来源绑定、真实动作位置、缺失帧、图集 crop/offset、层序及透明替换；不改输入项目。
- `tests/e2e/coverage-checkpoints.spec.ts`：实际男女素材入口定位、保留搭配、无标记 PNG、移动端缩放；另用明确标注的合成测试夹具验证外观 padding 和镜像。
- 夹具仅用于行为回归，不是人物画面质量证据。
