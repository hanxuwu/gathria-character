# 男版西装：袖口与下蹲前襟

这轮同时修正两类问题：抬臂时的直切、阶梯袖口，以及深蹲时马甲前襟被过度拉向髋部中点。
完整人物仍使用原 Kling 源图；只替换审核范围内的布料纹理，并恢复被旧袖边盖住的原拳头像素。

- **16 帧袖口**：63–66、74–80、97–101 使用新绘制的弯曲袖口与连续袖子布料。第 63 帧按源配置对应的远手标签处理。
- **20 帧前襟**：围绕 63、74、85、97 的相邻姿势渐变调整衣料映射，最大 12 原尺寸像素，相邻帧修正量最多变化 5 像素。轮廓、遮挡范围、透明度和身体倾斜保持不变。
- 合计 **27 帧更新、80 帧保持原生像素完全相同**。旧版已补齐的 2,555 个原背心像素没有重新露出。
