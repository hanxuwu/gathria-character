# 发型、表情与主题目录图

本目录给人物与服装总集提供实际素材预览。[manifest.json](manifest.json) 包含每张图的来源、当前选择项、素材版本、入口、原生尺寸和哈希；[integrity.json](integrity.json) 记录原尺寸 PNG 与头部裁切的像素检查。

| 展示项 | 数量 | 说明 |
| --- | ---: | --- |
| 原人物 | 2 | 男女原视角光头与基础服装 |
| 发型与发色 | 57 | 原视角男女各 6 款发型的 3 种发色，加侧视、双视角配对与落地候选的专用版本 |
| 表情预览 | 20 | 原视角及配对／候选外观中的表情，包含自然表情对照；同名表情可以绑定不同视角 |
| 完整主题造型 | 12 | 男女原画、像素童话 R2、仍可选择的像素童话 R1，各有基础与婚礼版本 |

合计 91 张展示卡，不等于 91 种独立设计。每张发型图都使用自然表情和原人物基础服装，便于比较头部；表情图使用固定发型。`.portrait.png` 是同一张全身原尺寸 PNG 的精确局部裁切，未缩放或重新绘制。

原视角的全身预览由当前 `AppearanceRenderer` 直接合成，配对和侧视使用各自绑定的银行与定位文件。所有主题预览来自对应 CharacterPack 的第一张原生 Idle 图。主题婚礼是发布时保留的完整成品，不代表今日最新衣橱的同名服装修订；完整主题不能拆成通用衣物混搭。

男版落地候选明确标为 `experimental`，旧主题标为 `earlier-selectable`。原视角旧表情另有 `styleRevision: earlier-selectable`。这些静态图用于选款，不证明整段动作已经通过美术验收；原发型与衣物已记录的接缝问题仍适用。

算法像素化是应用于当前完整换装结果的处理选项，组合数量没有固定上限，因此没有虚构一组“全部像素造型”。早期源图试验、未被当前目录引用的银行、用户本地工程，以及所有发型乘表情的排列组合不在此静态目录里。
