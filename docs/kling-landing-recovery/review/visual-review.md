# 第四版落地接跑：独立视觉检查

结论：**新的两个恢复姿态让角色在落地后更早抬脚，同时把起身分成较均匀的三步。原人物、日常装和西装均有改善，可作为实验候选继续验收。仍有滑脚和服装边缘问题，不能称为完全锁脚或最终美术版本。**

本次检查包含实际 `WardrobeCompositor` 合成结果、`advanceSidePlayback` 的固定镜头运动记录、左右 GIF 的帧序列、原尺寸关节与服装接缝，以及两种上衣／裤子混搭。角色头部没有单独稳定或缩放，鞋子没有逐帧对齐地面。

## 看到的改善

- 旧序列为 `85 → 88 → 107 → 108 → Run48`；新序列为 `85 → 新107 → 新108 → Run48`。原来 85→88 几乎保持双脚站住的阶段被移除，新的 107 已经开始卸掉近侧脚的承重。
- 新 107 保留较低的髋部与屈膝姿态，新 108 继续抬起近侧脚并向原跑步姿势过渡。头顶的上移从旧版最大的单步 **22 px**，变为 **13、13、12 px**。固定世界坐标下，头部继续向前移动，没有为压低头部跳变而加入倒退。
- 新姿态的肩颈、近侧手臂和支撑腿连接连续，没有保留生成图中的第二条下巴轮廓；腿部降低通过重新绘制屈膝与脚踝完成，没有把整段身体纵向压扁。
- 三套完整造型及“日常上衣＋西装裤”“西装上衣＋日常裤”的 107、108 原尺寸检查，未发现新增的腰部空洞、手腕断开或裤脚与鞋子脱节。发型与耳朵的位置跟随同一头部基准。左右方向的固定镜头逐帧检查未发现方向独有的断口。

## 排除速度或镜头造成的假改善

核对 [固定镜头记录](fixed-ground-review.json)：新旧版本在第 47–56 个相同时钟采样中的世界坐标一致，朝右每帧前进约 29.167 px，朝左方向相反，均对应 **700 px/s、24 FPS**。相机原点、0.5 倍展示比例和源素材地面锚点固定，没有追随头部或鞋子。六个 GIF 都是 10 帧、420 ms，新旧版本使用相同的 40/50 ms GIF 延迟分配。

三套造型共对比 27 个同帧号的原尺寸合成结果；变化仅包括每套造型重新绘制／适配的 107、108，共 6 个结果，其余 21 个结果保持一致。两个新姿态分别复制原片第 89 帧的 **37,158 个可见头部像素**，只做整数平移，没有重画脸部或缩放头部；具体记录见 [头部复制检查](../../../artwork/kling-landing-production/body/revision-4/head-copy-audit.json)。

按原尺寸像素 **alpha ≥ 128** 的轮廓计算，可见远侧鞋尖的总世界位移诊断从约 **47.667 px 降至 18.5 px**，减少约 61%。新序列的三段约为 8.167、1.167、9.167 px，仍不均匀。头顶高度也使用同一阈值，得到前述 22→13 px 的最大上移变化。[测量记录](contact-measurements.json) 同时保留了较低阈值 alpha > 32 的结果：位移约为 46.667→17.5 px，最大头部上移为 20→13 px。淡色抗锯齿会影响轮廓读数；鞋尖还受滚脚与透视影响，因此这些数字不能作为真实物理触地点的锁定误差。

## 尚未解决的视觉限制

- 原片的 85 与 Run48 本身存在头部角度、轮廓及上色差异；复制同一头部的新恢复帧不能消除两端原素材的全部变化。
- 新 107 的下蹲轮廓更明显，仍能看出补绘姿态与原片阴影的差别。支撑脚的剩余位移和远近脚的透视高度差仍然存在。
- 西装马甲在 107 的屈膝姿态中呈现更明显的斜向拉伸；两种裤子的膝部、裤脚边缘及部分袖口仍有原有的锯齿和生硬折痕。这轮解决的是恢复姿态与服装跟随，不能把这些继承的服装问题标为已修复。

## 实际工作台与完整导出

已检查实际工作台按钮导出的原人物、日常装、西装六个左右完整 GIF，均为 **77 帧、3210 ms**。原生 24 FPS 时长约为 3208.333 ms，3210 ms 来自 GIF 的 10 ms 延迟单位。完整序列在第 47–50 个采样呈现 `85 → 新107 → 新108 → Run48`，与固定镜头证据一致；三套造型没有新增的换衣错帧或单向断口。

完整 GIF 末尾是原片 Run56，重新播放时接原片 Run39，即已有跑步循环的相邻帧，没有在结尾额外插入待机或重新落地。这个循环检查不等于认为原片所有步态都已完美。
