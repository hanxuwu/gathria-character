Gathria Character — CharacterPack v1

Artwork version 6 uses AI-assisted illustration assets created for this project with OpenAI's image generation tool, then extracted into masked layers and composed by a deterministic local renderer. Source banks and preparation scripts are included in the repository. User-supplied images guided the visual style; those reference images are not bundled in this pack. No photos, remote services, or model calls are used during character customization, generation, export, or playback.

Generated sprites may be used, modified, and redistributed, including commercially, under the MIT License below. Retain its copyright and permission notice when redistributing. No visible in-game credit is required. This permission covers this project's original artwork; it grants no rights to third-party trademarks or identities.

Version 6 technically re-cuts the existing AI-assisted V5 wedding sources into clean anatomical layers, retains full authored face states, and applies a quieter deterministic gait. No new model-generated artwork was introduced in this revision. See scripts/prepare-polished-assets.py and docs/ART_POLISH_V6.md.

Motion version 3 corrects arm material ownership and leg joint connections only in the compact V6 run cycle. The original V6 idle and walk atlas rows, cadence, proportions and motion versions 1 and 2 remain preserved. It reuses the existing AI-assisted source artwork with local technical masks and joint composition; no new model-generated artwork or runtime model calls are used. See src/core/running-rig-v3.ts and docs/RUN_CONNECTIONS_REVIEW.md.

Prototype format: integration with the Gathria runtime is unverified.
