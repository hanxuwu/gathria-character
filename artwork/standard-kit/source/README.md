# Standard character kit: source artwork

One development-time OpenAI `image_gen.imagegen` call on 2026-10-19 produced
`head-hair.png`, using the existing Theo complete-character source as its style
and identity reference. The unmodified 1536×1024 RGBA output, exact prompt,
reference SHA256 and output SHA256 are retained beside this file.

The upper row supplies three complete bald head/short-neck expressions. The
lower row supplies two separate hair overlays. Preparation registers the
drawings to one head template and composites each hair variant over the same
three face sources. This is source production; the sheet is not an exported
character, runtime screenshot or proof of correct alignment.

The model did not obey exact requested dimensions/landmarks. Its low-alpha
glow, small stray nape-hair pixels on the bald drawings, differing wig scales
and face-opening boundaries require explicit offline ownership/registration.
These operations and their limits are recorded by the identity preparation
script; no runtime model or inferred color-based segmentation is introduced.

The two tops, trousers and two shoe designs are **reused artwork**, registered
as new derivatives of the preceding Ravi/Lina/Sage/Theo studies. They are not
claimed as new image-generation outputs. Their original PNGs, prompts and
provenance remain in their original directories. The garment registration
report records every input archive hash, transformation and preserved part.

Editable projects and actual Studio/CharacterPack outputs are delivered under
`../prepared/` and `../../../docs/standard-kit/`, respectively. Existing
IdentityPack/WardrobeItem/SkinPack/CharacterPack formats remain unchanged.
