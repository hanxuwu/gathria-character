# Source-bound pose repairs, Sprints 21–22

These are authored clothing derivatives, not recovered Kling clothing layers.
The approved male/female source CharacterPacks and registrations remain exact.

- Male: existing original suit donor reused; one crossing forearm boundary is
  reviewed in `source/male-hand-review.json`. `navy-suit-jacket-v5` retains all
  other poses and the visible distal hand. See `docs/kling-pose-review/HAND_REVIEWS.md`.
- Female: OpenAI image edit of actual native crouch pose 86. The complete output
  is retained with input, hashes and prompt in `source/female-provenance.json`.
  Only a traced interior cloth island supplies RGB folds. Generated face, body,
  background, silhouette and alpha are never used. `coral-daydress-v7` and
  `ivory-wedding-dress-v7` retain V6 ownership/alpha and protected anatomy.
  `scripts/prepare-kling-native-waist.py` records continuous pose weighting.

`prepared/*offline*` and `*native*` are authoring diagnostics, not app-export
acceptance evidence. Actual browser exports and review media belong under
`docs/kling-pose-review`. The old outfits remain available and saved projects
keep their original assets. The sharp right-waist outline and source video blur
are separate limitations; interior fold painting does not repair those shapes.
