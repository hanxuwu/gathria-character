# Cohesive artwork V5 production source

Created 16 October 2026 (Australia/Sydney) with the built-in OpenAI image-generation tool. `character-expression-bank.png` is an AI-assisted production input, **not a screenshot or exported animation**. The user supplied the existing bride/groom screenshot as the identity target and a bride sprite sheet as the style reference. Those user references are not redistributed here.

The source has six full-body characters: bride neutral/gentle/joyful above groom neutral/gentle/joyful. A second generation edit removed the embedded hair flowers for compatibility with the existing optional rose layer and changed the middle column to a small closed-mouth smile. The hair ornaments shown in application exports come from the previously recorded `expressive-source/flower-clip.png`.

The first image-generation request specified coherent warm Japanese chibi pixel illustration, a three-column/two-row source grid, continuous head/jaw/neck/shoulders, matched body scale and standing pose, three whole-face states, ivory/blush gown, navy suit and cream waistcoat. It explicitly requested transparent alpha, generous cell padding and no UI or evidence labels. The follow-up requested preserving all identities and anatomy while removing the bride hair flowers and reducing the middle-column smiles. The current source is the follow-up output, not the first draft.

`prepare-cohesive-assets.py` records actual source-cell bounds, landmarks, material ownership and anatomical face masks. Technical preparation thresholds alpha at 128, registers each complete authored head to the same neck landmark, separates rear hair without dropping the second disconnected tail, and cuts the wedding bodies with joint overlap. Each expression retains its own painted face and surrounding head pixels; no face patch is pasted into another expression. Skin ownership follows anatomical masks rather than hair-highlight brightness. Whole-face states remain material-aware so complexion is editable and eye ink stays independent of hair color.

Version 5 adds 25 namespaced layers. The V3 illustration bank and all V1–V4 renderers remain unchanged; `legacy-hashes.json` records their baseline hashes from commit `5846d59`. Old face types/hairstyles remain available. The new authored face states cover waves and short crop; bob and crest keep their previous open-eye portrait and are explicitly identified in the editor. Runtime is synchronous, local and deterministic, with no generation API.

Rebuild: `python3 scripts/prepare-cohesive-assets.py` using the project's existing Pillow/NumPy artwork dependencies. No image model is required to reproduce preparation. The artwork follows this repository's MIT licensing statement to the extent rights are held by contributors.

A third, targeted imagegen edit produced `garment-backplate.png`: it removes the top-row bride arms/hands and restores the fabric underneath while retaining the sheet layout. Only its waist-down skirt pixels are used. This prevents the original standing hands from remaining embedded in the skirt when the independent arm layers animate. The actual character arms continue to come from the original expression bank. The final request explicitly preserved gown shapes and coordinates, requested no skin remnants at the hips, and retained true transparent alpha.
