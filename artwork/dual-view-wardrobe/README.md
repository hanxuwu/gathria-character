# 双视角轻便日常服装：素材来源与边界

这批素材为男女两个 Kling 母版提供同一款「圆领棉背心 + 棉短裤」的原版三分之四视角和侧视版本。每个视角继续使用自己的原片、逐帧定位和衣料遮罩；没有将原版衣片缩放、扭曲或套到侧视身体上。

## 内容

- 2 个人物 × 2 个视角 × 2 套配色 × 上装/下装，共 16 个衣料包。
- 海盐日常：上装参考 RGB `80,139,158`，下装 `139,117,88`。
- 杏桃日常：上装参考 RGB `204,135,120`，下装 `75,104,128`。
- 男版默认海盐，女版默认杏桃；两个人物都可选两种配色。
- 鞋子保持各自原片中的白鞋，没有新增鞋子素材。

这是一款衣服的两套配色，不是两个不同剪裁的新套装。衣料目标 RGB 是材质映射的参考值；原片的明暗、描边和褶皱仍然参与最终颜色，因此不能把每个成品像素与单一色值相等作为验收标准。

## 原始材料

原版从 `docs/kling-wardrobe/catalog.json` 读取实际登记的 `teal-top` 与 `ochre-shorts`。男版对应 `male-full-outfits-v1`，女版对应 `female`。构建器检查每个原衣料包的实际 `sourceSha256` 和 `registrationSha256`，而不是仅凭人物名配对。

侧视从 `docs/kling-side-workspace/assets/` 读取男女各自的 `source.zip`、`registration.json`、`top.garment.zip`、`bottom.garment.zip`。这里使用已有背心/短裤的材质版本，没有借用衬衫、连衣裙或另一套裁剪定位。

完整输入文件地址、输入 SHA-256、原始材质参考色和输出校验见 [verification.json](verification.json)。供工作台读取的输出索引在 [catalog.json](../../docs/dual-view-wardrobe/assets/catalog.json)。

## 美术处理方式

使用项目现有 `GarmentAuthoringSession` 的 `owned-chromatic-ratio-v1` 流程离线生成材质变体：只在已有衣料 ownership 内修改非透明 RGB。保留原材质的明暗比例，按颜色距离限制作用范围，并保留深色描边。没有调用图片生成服务，没有重绘人物或替换原片。

侧视男版海盐、侧视女版杏桃已是目标配色，因此这 4 个衣料包只新增明确的资源 ID、名称和来源说明，PNG、ownership 和几何保持原始字节。其余 12 个衣料包通过上述现有材质流程构建。这个别名步骤不是一轮重新上色。

各视角的脸型、身体体积、动作、光照本来就不同。这里承诺相同款式和配色选择，并不声称两段视频具有相同的身体像素、帧数或光照。原版庆祝动作保持可用，侧视素材没有庆祝动作，未据此合成新动作。

## 构建与技术证明

```sh
node scripts/build-kling-dual-view-wardrobe.mjs
node scripts/build-kling-dual-view-wardrobe.mjs --check
```

构建器自行启动 `127.0.0.1:5186` 的 Vite 与 Chromium，通过现有导入、服装创作和合成 API 生成素材。需要已有依赖和 Chromium；可设置 `CHROMIUM_PATH`。`--check` 重新生成并逐字节核对衣料 ZIP、配置、报告和原生预览。

每个包检查帧定位完全相同、ownership PNG 字节完全相同、atlas alpha 完全相同，以及所有改色像素均属于不透明衣料。每套搭配遍历全部登记姿势，检查身体在衣料 ownership 之外逐像素不变、整体 alpha 不变，并经过现有运行时头部/手部保护校验。

`reports/` 保留每件服装的材质配置、改色像素统计，以及原有作者工具给出的困难姿势清单。清单中的 `pending` 是工具保留的审阅状态，技术通过不代表这些姿势获得美术认可。

`native-previews/` 是上述真实合成器直接输出的透明原生 PNG，每个动作取一个检查姿势。它们是素材构建证据，不替代在工作台中保存、重开、导出 GIF 和独立播放器的完整验收。

## 已知限制

- 原始背心和短裤的轮廓、褶皱、视频帧之间的形变被原样保留；本批没有修正这些已有问题，也没有新增版型。
- 原版与侧视的照明、线条厚度和材质明暗不同。相同参考配色仍可能呈现亮度差异；后续若要统一美术，需要独立审核两边素材，不应牺牲原人物来机械匹配像素。
- 原生 PNG 人工检查覆盖男女的默认站姿、另一配色的跑步姿势，以及默认配色的跳跃下蹲姿势。原版跑步/跳跃画面的模糊程度高于侧视，女版原版短裤左侧还保留较明显的接缝高光；这些现有素材差异没有被隐藏或重新描画。
- 其他已有衬衫、外套和裙子没有相同的双视角剪裁，本批未把名称相似的衣服冒充同款。新增款式必须提供两个视角各自完整的姿势与遮挡素材。

美术观察和最终工作台导出证据见本轮项目交付说明；技术证明仅说明这次材质处理没有越过已有素材边界。
