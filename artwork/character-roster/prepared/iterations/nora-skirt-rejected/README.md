# Rejected Nora skirt retargeting

The matching Rose skirt and own-axis V5 flat shoes do not form a complete valid
run with the existing shared motion/support model. The original assembled
project is retained at `../original-motion/nora.rig.zip`; its exact errors are in
that directory's registration report. This directory contains the portable
source items and the partial hip-local Motion V1 diagnostic, which also fails
contact keys 0, 10 and 11. Its partial PNGs are diagnostic frames, not a successful
loop or a delivered CharacterPack.

Bounded stride/lift and uniform crouch trials are retained separately under
`../retarget-preflight/`. Shortening motion to zero stride was rejected. No
anatomy stretching, fake shoe axis or old independent shoe-pitch fallback is
used in the playable final roster.

Final Nora keeps the new identity and ivory Rose blouse, but uses the proven
Sage shorts/sneakers set in coral colors and the same compact V2 motion profile
as Lina. This is a deliberate compatible outfit selection. The original skirt
reference is not fully fulfilled and remains future retargeting work.
