# 男版双视角休闲衬衫与长裤

这组资源将已有、分别绘制和定位的原版与侧视「闭合门襟短袖翻领衬衫 + 全长休闲裤」整理为同一逻辑款式。相对于首批背心/短裤，袖子、领口、门襟和裤腿是实际改变覆盖范围的衣料；没有将原版衣片缩放到侧视，也没有重新生成人物。

## 原画选择

原版采用 `teal-camp-shirt-v5` 和 `ochre-chinos-v1`，保留已有闭合门襟、短袖、翻领、连贯袖口与完整裤腿的绘画。侧视采用最新 `male-shirt.garment.zip` 和 `male-trousers.garment.zip`，保留已有独立绘制的侧面领口、门襟、袖子、裤褶，以及先前通过审阅的手边和领口修复。

原版 `terracotta-overshirt-v1` 曾作为候选检查，但它是敞开门襟、露内搭的外衫；不能与侧视闭合衬衫仅凭颜色相近而登记为同款，因此未选用。原版与侧视仍有来自各自绘画的领角、褶皱和明暗差异，不能称为完全相同的纹理。

这些都是仓库中有来源记录的生成辅助绘画与逐帧衣料处理结果。本轮没有调用新的人物或服装图片生成，也没有宣称这是新画出的八套服装；输出是同一个已绘制版型、两种配色、两个视角、两个部位，共八个资源包。

## 配色与兼容

- 海盐：衬衫参考 RGB `80,139,158`，长裤 `139,117,88`。
- 暖杏：衬衫参考 RGB `204,135,120`，长裤 `75,104,128`。
- 使用现有 `owned-chromatic-ratio-v1` 离线材质流程。各原衣料页完全不透明、亮度 80–210 范围的中位 RGB 作为记录的材质基色；原画明暗与深色描边仍然保留。
- 新配色保持各原衣料 atlas 尺寸、逐帧矩形/偏移、ownership PNG 字节和 alpha 完全相同。
- 原版新款绑定 `docs/dual-tailored/assets/male/male-ankle-reviewed-v1.registration.json`。它只修正第 54 帧把后侧脚踝误标为 `nearHand` 的六个轮廓顶点；旧定位、旧衣料与旧棉背心/短裤保持原文件不变。新衬衫仅改绑定，PNG 与 ownership 字节完全等于 `teal-camp-shirt-v5`；新长裤仅修补该帧脚踝及原缺口边线。
- 侧视新剪裁继续绑定已审阅的 `artwork/kling-side-expansion/templates/male.registration.json`。新系列可分别保留原片上装或原片短裤，但不混入旧系列的彩色棉背心/短裤。两种简单改绑方案均被实际保护检查和画面检查否定，见 [拒绝的绑定试验](rejected-binding/README.md)。原有棉衣包、原版旧定位及侧视定位都保持不变。

## 定位记录

`original-anchors.json` 和 `side-anchors.json` 保存项目实际使用的每帧领口、肩、肘、腕、腰、髋、膝、踝与脚尖位置，以及原置信度和保护范围。它们是从画面估计并审阅的衣料参考位置，不是视频自带的准确骨骼数据。

新衬衫的袖口跟随该视角的上臂范围及前臂遮挡；长裤保留既有髋—膝—踝绘画与鞋口保护。不同视角不得共享坐标或帧编号。替换新的剪裁仍需自己的姿势与遮挡图。

## 构建和审阅

```sh
python scripts/prepare-dual-tailored-male-cuff.py --output docs/dual-tailored/assets/male
node scripts/build-dual-tailored-male.mjs
node scripts/build-dual-tailored-male.mjs --check
```

脚本使用独立 Vite `5188` 和 Chromium，通过应用真实的导入、服装作者和合成器生成资源与透明预览。`--check` 重新执行并逐字节对比 ZIP、配置、透明 PNG 和检查报告。

产物目录：`docs/dual-tailored/assets/male/catalog.json`，包含八个新衣料包，以及来源/定位/资源哈希。`verification.json` 记录每个视角、每种配色、衬衫/原片上装与长裤/原片短裤四种组合的全部原生姿势检查。每次实际渲染检查衣料归属之外 RGBA 完全一致，并执行项目头部/手部保护。真实新剪裁允许在衣料范围内扩展 alpha，因此没有把「全图 alpha 与背心短裤原片相同」当成正确目标。

`previews/` 是真实应用合成器的 PNG，包含站立、走路、跑步、跳跃、原版庆祝及指定困难姿势。[并排姿势检查](paired-poses.png) 使用这些 PNG 做布局与标注，不改变衣料。最终界面导出的 GIF、CharacterPack 和独立播放器验收由本轮工作台交付另行记录。

## 保留的视觉限制

原版运动帧的模糊、原有衣料折痕与下蹲压缩仍然存在。侧视 jump 67/89/91 的部分灰色肩颈边界混合了模糊源肤色及受保护区域；此前扩大覆盖的方案已经因伤及源皮肤证明而被拒绝，本轮不为掩盖接缝而重画这些身体像素。

本轮构建执行 1,560 次原生姿势组合检查（两种视角共 195 帧 × 两种配色 × 四种选择），全部通过；逐字节重新生成 ZIP、索引、透明 PNG 和报告也通过。新增配色只修改衣料内 RGB，原版及侧视的动作帧序和时间没有更改。

本轮选择最新已有的连续袖口和局部领口修复作为基线，但不把以前修过的地方算作本轮新增补绘。实际混搭和新配色的视觉判断须依据导出预览；技术一致性检查本身不证明所有布料运动已完全自然。

## 本轮脚踝归属修复

实际界面导出的跑步第 4 帧（原始 `frameId:54`）暴露了一个三角形肤色洞。逐层核对后，原 `nearHand` 多边形把下方后侧脚踝与拳头连成了同一块皮肤。其余 15 个跑步姿势，以及待机、行走、跳跃和庆祝的手部保护叠图均检查过，没有同样的脚踝连通突起。

[原图／旧保护／新保护对比](ankle-review/source-hand-ankle-diagnostic.png) 明确保留拳头轮廓，删掉六个属于脚踝的突起顶点，共 1,133 个保护像素。旧语义手部遮罩比旧多边形在局部多出少量边缘像素；仅在已审阅的同一脚踝区域内修正，排除鞋子和新的真实手部保护。

旧语义遮罩额外包含 60 个同属脚踝的边缘像素，合计恢复 1,193 个衣料归属像素。局部共修改 1,529 个原色衣料像素。

裤料补充沿用仓库已有 `full-outfits-v1/designs.png` 画出的休闲裤，通过原长裤离线贴合流程恢复该表面，并替换缺口四像素邻域的假描边；未重画人体。[局部 3 倍对比](ankle-review/cuff-comparison-3x.png) 是该步骤的原生尺寸离线合成检查，最终验收仍使用实际应用导出。其余 87 个原版姿势、所有侧视素材、全套源视频帧与动作时长不变。

`ankle-review/cuff-audit.json` 记录旧/新绑定哈希、修复范围、衣料像素数量及 PNG/ownership 复核。`scripts/prepare-dual-tailored-male-cuff.py --output docs/dual-tailored/assets/male` 可从已跟踪的旧源文件重新生成；不依赖临时目录或忽略的 staged 文件。

将实际界面保存的修复前衣柜包逐帧解码，与最终两色衣料比较：两套衬衫所有 RGBA/ownership 完全相同；两套长裤只有 frame54 有差异，其他 87 帧完全相同。详见 `ankle-review/palette-regression.json`。最终脚踝修复后重新执行 1,560 次原生混搭检查及 `--check` 逐字节再生成，全部通过。
