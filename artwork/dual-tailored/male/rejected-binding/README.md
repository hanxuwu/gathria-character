# 拒绝的跨定位混搭方案

这组图是独立解码已有 ZIP 后的素材诊断，不是最终工作台导出，也没有把试验中的衣料投入运行。

1. 将旧棉背心/短裤图片和 ownership 原样改绑到新剪裁定位：海盐配色中，上下装合计 7,218 个 ownership 像素与新的头/手保护冲突，其中 5,793 个像素的衣料颜色不同于原片，严格合成器拒绝。
2. 仅释放这些冲突 ownership：会在 frame 49、59、72 等姿势恢复明显的灰色原背心带，图中第三列是这个**被拒绝**的试验。技术上可满足保护规则，但视觉退步，不能仅为测试通过而接受。
3. 反向把新剪裁衣料改绑旧棉衣定位：共 148,449 个改变过的衣料像素被旧保护边界覆盖。衬衫涉及 45 帧，长裤涉及 24 帧；旧 head 范围在 frame 75 覆盖 5,143 个衬衫像素。旧定位中的过宽边界正是此前新剪裁需要独立定位的原因，反向改绑不是可用方案。

旧棉衣素材与新剪裁素材各自保持原绑定和保护。这里不改注册表、不放宽头/手保护，也不声称颜色相近的跨定位混搭已经安全可用。后续需要单独完成可视手部边界和衣料归属的共同审阅，再决定是否登记兼容版本。

运行 `python3 artwork/dual-tailored/male/rejected-binding/audit.py` 可重新独立解码源文件、核对这两种绑定的碰撞计数并生成拒绝方案对比图。需要 Pillow、NumPy、SciPy；脚本只写本诊断目录，不生成或改写运行时衣料包。
